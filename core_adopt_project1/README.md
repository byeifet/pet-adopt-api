# PetAdopt API - Django REST Framework

API RESTful profesional desarrollada para la gestión de adopción de mascotas, implementando buenas prácticas de backend, seguridad con Django REST Framework y auditoría asistida por Inteligencia Artificial.

## 🛠 Tecnologías Utilizadas
* Python
* Django & Django REST Framework (DRF)
* SQLite (Base de datos local)
